# 大乐透/双色球合规 H5 选号服务设计

日期：2026-06-02

## 目标

建设一个面向中国大陆成年用户的 H5 网站，提供超级大乐透和双色球的号码生成、历史开奖数据分析、组合解释和原创正能量寄语。产品只销售号码生成与数据分析服务，不销售彩票，不代购彩票，不出票，不合买，不追号，不兑奖，不承诺中奖。

首版先做 H5，验证用户使用、留存和变现意愿；产品稳定后再规划微信小程序。

## 产品定位

产品定位为“大乐透/双色球智能选号助手”。用户每天可以免费生成 3 组号码；免费次数用完后，可以通过广告解锁或购买次数包/会员获得更多生成次数。所有付费权益均为数字内容服务，不涉及彩票交易。

核心原则：

- 合规优先：不提供任何互联网售彩、代购、出票或购彩跳转。
- 诚实表达：号码生成基于随机、均衡筛选和历史数据参考，不构成中奖预测。
- 低刺激设计：避免暴富、包中、稳赚、翻身、投资收益等诱导性表达。
- 理性使用：核心页面展示 18+、随机性、理性购彩和量力而行提示。

## 用户与场景

首版服务两类主要用户：

- 普通购彩者：想快速获得几组顺眼号码，操作越简单越好。
- 数据型用户：希望查看历史开奖、冷热号、遗漏值、奇偶比、区间分布等基础分析。

不把专业预测、社区晒单、中奖故事、合买组织作为首版目标。

## 信息架构

### 首页

首页承担快速进入选号的职责：

- 产品名和 18+ 理性使用提示。
- 超级大乐透、双色球入口。
- 今日剩余免费生成次数。
- 最近期开奖信息。
- 不售彩、不代购、不出票声明。

### 选号页

选号页是核心工具页：

- 彩种切换：大乐透、双色球。
- 生成模式：随机生成、均衡生成、数据参考。
- 号码结果展示：按彩种使用不同颜色区分前后区、红蓝球。
- 组合解释：奇偶比、大小比、区间分布、连号情况、历史数据参考说明。
- 原创正能量寄语。
- 剩余次数展示。
- 次数用完弹层：广告解锁、购买次数包、开通会员。
- 合规提示：仅供娱乐参考，不构成中奖预测。

首版不提供“复制去购买”“立即购彩”“下单”“出票”等动作。

### 数据分析页

数据分析页服务留存和搜索流量：

- 最新开奖记录。
- 历史开奖列表。
- 热号和冷号。
- 遗漏值。
- 奇偶分布。
- 大小分布。
- 区间分布。
- 奖池趋势。

页面声明：开奖数据来自公开渠道整理，实际结果以官方公告为准。

### 我的页面

我的页面管理用户权益和合规材料：

- 今日剩余免费次数。
- 广告解锁次数。
- 会员状态。
- 次数包余额。
- 生成历史。
- 订单记录。
- 服务协议。
- 隐私政策。
- 理性使用声明。
- 18+ 声明。

## 彩种规则

### 超级大乐透

- 前区：1-35 选 5 个号码。
- 后区：1-12 选 2 个号码。
- 每组号码必须合法、去重、排序展示。

### 双色球

- 红球：1-33 选 6 个号码。
- 蓝球：1-16 选 1 个号码。
- 每组号码必须合法、去重、排序展示。

## 选号策略

系统内部将算法命名为“选号策略”，不使用“预测模型”作为产品表达。

### 随机生成

按彩种规则完全随机生成合法号码。该策略最适合作为合规基线，也用于对照测试。

### 均衡生成

在合法随机号码上进行筛选，使组合满足基础分布条件，例如：

- 奇偶比不过度极端。
- 大小比不过度极端。
- 区间分布相对分散。
- 连号数量受限。
- 和值落在历史常见区间内。

均衡生成只表示组合结构更均衡，不表示中奖概率更高。

### 数据参考

根据历史开奖统计生成带权重的候选组合，参考维度包括：

- 近期热号。
- 长期冷号。
- 遗漏值。
- 最近若干期重复情况。
- 历史分布区间。

页面必须说明：历史数据只用于娱乐分析，彩票开奖具有随机性，历史分布不影响未来开奖结果。

## 结果解释

每组号码生成后保存以下信息：

- 彩种。
- 策略。
- 号码。
- 生成时间。
- 组合解释。
- 原创寄语。
- 合规提示版本。

组合解释以简短、可读、克制为原则。例如：

- “本组红球奇偶比为 3:3，分布较均衡。”
- “前区号码覆盖低中高三个区间，未出现过度集中。”
- “历史数据仅用于娱乐分析，不构成中奖预测。”

## 正能量寄语

每组号码附赠一句原创短句，用于增强仪式感和分享体验。

规则：

- 默认使用原创短句，不署现代名人姓名。
- 可以使用公版古诗词风格表达，但不虚构出处。
- 不把寄语写成中奖暗示。
- 不出现“必中奖”“转运暴富”“一夜翻身”等表达。

示例：

- “今天适合稳稳前进，把好运留给有准备的自己。”
- “认真生活的人，也值得被温柔地照亮一下。”
- “把期待放轻，把脚步走稳。”

## 权益与商业化

### 免费额度

每个用户每天免费生成 3 组号码。免费额度按自然日重置。

### 广告解锁

免费额度用完后，用户可通过观看广告解锁额外生成次数。首版先实现模拟广告解锁，后续接入真实激励广告 SDK。

### 付费权益

付费权益包括：

- 次数包：购买固定数量的号码生成次数。
- 会员：每日更多生成次数、高级数据分析、更多生成历史保存。

支付文案必须明确：

- 购买的是号码生成与数据分析服务。
- 平台不销售彩票。
- 平台不代购彩票。
- 平台不承诺中奖。

首版先实现模拟支付和订单模型，不接真实支付。

## 合规边界

禁止功能：

- 互联网售彩。
- 代购彩票。
- 出票。
- 合买。
- 追号。
- 兑奖。
- 购彩跳转。
- 返佣导流。
- 专家包中。
- 中奖率提升承诺。

禁止文案：

- 立即购彩。
- 下单。
- 出票。
- 跟投。
- 必中。
- 包中。
- 稳赚。
- 投资回报。
- 提高中奖率。
- 翻身致富。

必须展示的提示：

- 本平台仅提供号码生成与数据分析服务。
- 本平台不销售彩票，不代购彩票，不出票。
- 生成结果仅供娱乐参考，不构成中奖预测。
- 彩票开奖具有随机性，请理性使用、量力而行。
- 未满 18 周岁不得使用本服务参与任何彩票相关活动。

## 数据来源与同步

开奖数据采用自动同步为主、手动导入兜底的策略。

### 初始数据

开发阶段由导入脚本导入超级大乐透和双色球历史开奖数据。用户不需要手动逐条录入数据。

初始字段包括：

- 彩种。
- 期号。
- 开奖日期。
- 开奖号码。
- 销售额。
- 奖池。
- 一等奖注数。
- 一等奖奖金。
- 数据来源。

部分公开数据缺失时，允许销售额、奖池、奖金等字段为空，但期号、日期、号码必须完整。

### 定时同步

上线后通过定时任务在开奖日后同步最新期开奖数据。

同步流程：

1. 拉取公开开奖数据。
2. 校验期号、日期和号码合法性。
3. 与已有数据去重。
4. 写入数据库。
5. 记录同步日志。
6. 异常时通知管理员。

### 手动兜底

后台保留 CSV 导入和修正能力，用于数据源异常或历史数据补齐。CSV 导入必须经过同样的数据校验。

## 数据模型

建议核心表：

- users：用户基础信息和年龄确认状态。
- lottery_types：彩种规则。
- lottery_draws：历史开奖数据。
- number_generations：用户生成记录。
- entitlements：用户可用次数和会员权益。
- entitlement_events：权益流水。
- orders：服务订单。
- ad_unlock_events：广告解锁记录。
- compliance_notices：合规提示版本。
- sync_jobs：开奖数据同步日志。

## 服务边界

### LotteryCatalog

管理彩种规则、号码范围、开奖频率和概率说明。

### DrawData

负责历史开奖数据、最新开奖、基础统计和数据校验。

### NumberGenerator

负责随机、均衡、数据参考三种选号策略，并输出组合解释。

### Entitlement

负责每日免费次数、广告解锁次数、会员权益和次数包扣减。

### PaymentAndAdUnlock

负责模拟支付、订单记录、广告解锁记录和后续真实支付/广告接口适配。

### Compliance

统一管理页面提示、敏感词、合规声明和付费服务说明。

## 技术建议

推荐技术栈：

- 前端：Next.js + React，先做移动优先的 H5 响应式页面。
- 后端：Next.js API 路由或独立服务。
- 数据库：PostgreSQL。
- 缓存：Redis，用于限流、免费次数和短期状态。
- 定时任务：同步开奖数据。
- 测试：单元测试、接口测试、浏览器端流程测试。

MVP 可以先简化为：

- Next.js 全栈应用。
- PostgreSQL 或 SQLite。
- 模拟广告。
- 模拟支付。
- 脚本导入初始开奖数据。

## 错误处理

号码生成失败：

- 不扣减用户次数。
- 展示“生成失败，请稍后重试”。
- 记录错误日志。

权益扣减失败：

- 不展示生成结果。
- 提示用户重试。
- 保证权益流水和生成记录一致。

开奖数据同步失败：

- 保留上一期可用数据。
- 在管理日志中标记失败原因。
- 前端不展示未校验的新数据。

CSV 导入失败：

- 返回具体错误行号和原因。
- 不写入部分失败数据。

支付或广告模拟失败：

- 不增加权益。
- 给出明确提示。
- 保留事件日志，便于排查。

## 验收标准

产品可用：

- 用户可以选择大乐透或双色球。
- 用户每天能免费生成 3 组号码。
- 免费次数用完后无法继续免费生成。
- 用户可以通过模拟广告或模拟付费获得额外次数。
- 每组号码符合对应彩种规则。
- 每组号码都有组合解释和原创寄语。
- 用户能查看历史开奖和基础统计。

合规可控：

- 不存在彩票销售、代购、出票、合买、追号、兑奖流程。
- 不存在购彩跳转。
- 不存在中奖承诺。
- 支付和解锁文案明确说明购买的是号码生成与数据分析服务。
- 核心页面都有随机性和理性使用提示。

技术可测：

- 号码生成、权益扣减、数据导入和合规检查均有测试。
- 主要用户流程可以通过浏览器测试跑通。
- 开奖数据同步失败时系统可以稳定降级。
